# Safer Calumpit: Crime Analytics and Prediction Project

## Project Overview
Safer Calumpit is an end-to-end crime analytics project that analyzes local blotter records to uncover patterns, trends, and potential risk indicators. The project integrates data cleaning, exploratory data analysis (EDA), interactive dashboard visualization, and predictive modeling concepts to support data-driven public safety strategies.

---

## Problem Statement
Crime data is often reviewed case by case without identifying long-term patterns. This project aims to analyze historical blotter records to detect trends by type, location, and time, and explore the potential for predictive modeling.

---

## Project Phases

### Phase 1: Data Analytics & Visualization
- Data cleaning and preprocessing
- Handling missing and inconsistent values
- Standardizing crime categories
- Creating calculated fields for time-based analysis
- Interactive dashboard development

### Phase 2: Predictive Modeling (Concept & Development)
- Feature selection and preparation
- Exploration of classification techniques
- Model evaluation planning
- Framework for future deployment as a prediction system

---

## Dashboard Features
- Crime frequency by type
- Monthly and yearly trend analysis
- Location-based crime distribution
- Interactive filters and slicers
- Summary KPI indicators

---

## Tools and Technologies
- Microsoft Power BI
- Microsoft Excel

## Key Insights
- Certain crime types show recurring temporal patterns.
- Some locations consistently record higher incident counts.
- Time-based analysis reveals peak periods of crime occurrence.
- Visualization enhances understanding of high-risk trends.
